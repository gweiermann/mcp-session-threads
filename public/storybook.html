Session Threads — Component Storybook

Every component and every rendered situation the board can show. Each story is built from a thread fixture and run through the same thread-logic.js + components.js the live board uses — so what you see here is exactly what the real board renders for that state.

Under each story: the board state that triggers it, and the decision the logic reached (the status chip + which predicates fired). Start with the Sandbox to dial in any situation by hand.
